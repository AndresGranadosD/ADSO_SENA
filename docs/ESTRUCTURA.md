# Estructura de evidencias ADSO

Cada evidencia se organiza usando la siguiente convención:

```text
GA[número de guía]/[código de competencia]/[actividad]/[evidencia]/
```

Ejemplo:

```text
GA4/220501095/AA2/EV01/
```

Dentro de cada carpeta de evidencia se recomienda guardar:

```text
[código-completo].tex
referencias.bib
README.md
build/                 # Ignorada por Git; contiene el PDF y auxiliares
```

No se añade todavía ninguna evidencia en esta configuración inicial.
